# Security Policy

This tool reads local clipboard image data and writes temporary PNG files under the macOS temp directory. It does not send data over the network and should not collect telemetry.

Please do not report unrelated Ghostty security issues here. Report Ghostty issues to the Ghostty project.

For issues in this bridge, open a GitHub issue with:

- macOS version
- Ghostty version
- Hammerspoon version
- exact reproduction steps
- whether the clipboard contained text, image data, or both
